# Informe de reducción de datos espectroscópicos

Informe sobre el procedimiento de reducción de datos espectroscópicos, compuesto por 8 pipelines. Cada pipeline se documenta con el código, sus salidas ya guardadas (gráficos y tablas) y el texto explicativo, de modo que **se puede revisar completo en línea, sin ejecutar nada**.

## Cómo leer este informe

Haz clic en cada enlace del índice: GitHub muestra los notebooks directamente en el navegador, con texto, código y resultados.

## Estructura de cada pipeline

1. Qué hace el pipeline (comprensión)
2. Corrida (código con salidas)
3. Mejoras realizadas
4. Análisis de errores
5. Discusión
